# NetOps Guide——网络设备配置与故障排查多模态知识助手

**技术栈：** Python、FastAPI、Uvicorn、LangGraph、LangChain、阿里百炼 Qwen、MinerU、BGE-M3、BGE-Reranker-v2-M3、Milvus、Neo4j、MongoDB、MinIO、PyMilvus、FlagEmbedding

## 项目说明

面向无线网关、AP、AC 等网络设备的配置查询与故障排查场景，构建集多模态文档导入、知识存储、混合检索和证据问答于一体的 RAG 系统。系统将 PDF/Markdown 手册加工为带商品型号、章节层级、图片语义和来源信息的知识切片；查询阶段依次完成设备型号确认、问题改写、多路召回、融合精排和答案生成，输出包含配置命令、操作步骤及资料引用的回答。

## 工作内容

### 1. 多模态手册解析与标准化入库

- 使用 MinerU 将 PDF 技术手册转换为 Markdown，保留章节层级、正文、代码块和图片引用；通过 FastAPI 后台任务和 LangGraph 编排文件校验、解析、切分、向量化及入库节点。
- 根据 Markdown 图片路径定位图片所在位置，提取最近标题、上文和下文，与图片 Base64 数据共同提交视觉模型生成中文语义标题；将图片上传 MinIO，并把本地图片引用改写为可访问 URL，使图片信息能够参与后续检索和答案引用。
- 按 Markdown 标题层级拆分章节，对超过长度上限的内容使用 `RecursiveCharacterTextSplitter` 按段落、换行和中文标点递归切分；对同一父标题下的短切片进行贪心合并，避免切片过碎导致语义缺失。

### 2. 商品型号识别、向量化与知识存储

- 从文件标题和前 5 个文档切片构建商品识别上下文，调用 Qwen 提取标准商品名；使用 BGE-M3 同时生成 Dense 与 Sparse 向量，建立独立商品名称集合，用于查询前的型号确认。
- 将 `商品型号 + 章节标题 + 正文` 作为切片向量化内容，批量生成 Dense/Sparse 向量；在 Milvus 中分别建立语义向量索引和稀疏倒排索引，写入正文、标题、父标题、商品名等元数据，并回填 `chunk_id` 作为多路召回去重键。
- 调用 Qwen 从切片中抽取设备、部件、操作、步骤、工具、条件和告警等实体关系；通过实体类型白名单、关系类型白名单、空值清理和去重后，将实体向量写入 Milvus、关系写入 Neo4j，并通过 `chunk_id` 保留原文溯源关系。

### 3. 商品约束的混合检索与多路融合

- 结合 MongoDB 历史会话调用 Qwen 提取当前问题中的商品型号并改写为独立问题；将候选型号编码为 Dense/Sparse 向量，在商品集合中进行混合匹配，确认后使用 `item_name` 标量过滤限定检索范围，减少不同设备手册之间的串库召回。
- 并行执行两路本地检索：一路直接对改写问题执行 BGE-M3 混合召回；另一路先使用 HyDE 生成技术文档风格的假设内容，再对“原问题 + 假设文档”向量化召回，补充用户表达与手册语言之间的语义差异。
- 使用 RRF 按 `chunk_id` 融合两路排名并累加共同命中文档的得分；将候选文档与用户问题组成句对，通过 BGE-Reranker-v2-M3 进行交叉编码精排，并根据相邻分数绝对差和相对差执行动态截断。

### 4. 基于证据的答案生成与工程实现

- 实现 LangGraph 答案生成节点，将精排文档整理为带编号的上下文并控制最大输入长度，通过 Prompt 约束 Qwen 基于检索证据作答，支持关键结论标注 `[资料N]`、图片链接引用、资料不足拒答和提示词注入防护。
- 设计型号标准化与候选确认策略，对 `LA2608` 等含数字型号简称进行唯一商品映射；对于多个同系列候选，生成澄清选项并提前返回，确认后将标准商品名和改写问题写回 State。
- 设计 LangGraph 并行检索分支的增量 State 更新与异常降级机制；实现 MinIO Bucket 自动初始化、知识图谱异步任务异常传递，以及节点耗时、输入输出数量、执行状态等 JSONL 可观测性埋点，并编写 6 个离线单元测试。

## 真实评测

- 基于 H3C LA2608 用户手册构建 **10 条人工标注问题**，覆盖型号简称、产品兼容性、拨号配置、DNS、静态路由、VLAN、DHCP 和连通性验证。
- 最终评测结果：**10/10 问题完成正确商品路由，Top-3 命中 9/10，MRR 为 0.90**。
- CPU 环境下完整查询链路平均耗时 **22.82 秒**、P95 **33.16 秒**，各节点执行状态、耗时及输入输出数量均写入 JSONL 日志。

> 以上数据属于10条人工标注问题的小规模功能评测，不代表生产环境准确率。
